A job is one backup definition: which paths, which destinations, how often.

```yaml
jobs:
  - name: system
    sources: [/etc, /root, /home]
    exclude: ["*.tmp", ".cache", /home/*/Downloads]
    destinations: [hetzner, nas]
    schedule: "15 3 * * *"
    compression: zstd
    one_file_system: true
    timeout: 6h
    encryption:
      passphrase: ${BACKUP_PASSPHRASE}
    retention:
      keep_last: 7
      keep_days: 30
```

## Options

<ParamField path="name" type="string" required>
  Unique. Letters, digits, `.`, `_` and `-`. Used in snapshot names, so changing it starts a new snapshot series.
</ParamField>

<ParamField path="sources" type="string[]" required>
  Absolute paths to files or directories.
</ParamField>

<ParamField path="destinations" type="string[]" required>
  Names from the `destinations` section. The snapshot is streamed to all of them in parallel.
</ParamField>

<ParamField path="exclude" type="string[]">
  Patterns for files and directories to skip. See [Exclude patterns](#exclude-patterns).
</ParamField>

<ParamField path="schedule" type="string">
  When the daemon runs the job. Leave it out for manual-only jobs. See [Schedules](#schedules).
</ParamField>

<ParamField path="compression" type="string" default="zstd">
  `zstd`, `gzip` or `none`. Use `none` for data that's already compressed (media, `mongodump --gzip` output, disk images).
</ParamField>

<ParamField path="compression_level" type="integer">
  zstd: 1–22 (default ≈3). gzip: 1–9 (default 6).
</ParamField>

<ParamField path="one_file_system" type="boolean" default="false">
  Don't descend into other mounted filesystems. The mount point directory itself is still recorded.
</ParamField>

<ParamField path="timeout" type="duration">
  Abort the run if it takes longer than this, e.g. `90m` or `6h`. After hooks still run.
</ParamField>

<ParamField path="encryption" type="object">
  See [Encryption](/configuration/encryption).
</ParamField>

<ParamField path="retention" type="object">
  See [Retention](/configuration/retention).
</ParamField>

<ParamField path="hooks" type="object">
  See [Hooks](/configuration/hooks).
</ParamField>

<ParamField path="notify" type="object">
  Per-job Discord and webhook targets, in addition to the global ones. See [Notifications](/configuration/notifications).
</ParamField>

## Schedules

Standard five-field cron expressions (`minute hour day-of-month month day-of-week`) in the server's local time, or descriptors:

| Schedule | Runs |
|---|---|
| `"15 3 * * *"` | Daily at 03:15 |
| `"0 */6 * * *"` | Every 6 hours, on the hour |
| `"30 2 * * 0"` | Sundays at 02:30 |
| `"@daily"` / `"@hourly"` / `"@weekly"` | What it says on the tin |
| `"@every 4h"` | Every 4 hours from daemon start |

`nobackups list` shows each job's next run time. If a run is still going when its next slot comes up, that slot is skipped and logged rather than starting a second copy.

<Tip>
  Spread jobs out (03:15, 03:45, …) instead of starting everything at midnight. Your disks, your bandwidth and your storage provider will thank you.
</Tip>

## Exclude patterns

Two kinds of pattern, using shell globs (`*`, `?`, `[abc]`):

| Pattern | Matches |
|---|---|
| **No `/`**: `*.log`, `node_modules`, `.cache` | Any file or directory with that **name**, anywhere under the sources |
| **Contains `/`**: `/var/lib/docker`, `/home/*/Downloads` | That **full path**, and everything under it |

```yaml
exclude:
  - "*.tmp"              # any .tmp file
  - node_modules         # any node_modules directory (and its contents)
  - /home/*/.cache       # each user's .cache
  - /var/www/*/cache     # cache dirs one level under /var/www
```

<Note>
  `*` doesn't match across `/`. To exclude every directory named `cache` at any depth, use the name form `cache` rather than `*/cache/*`.
</Note>
